# NEC License Preparation App – *NecLicensePreparation*

A mobile application built with **Flutter** and **Supabase** designed to help engineering graduates prepare for the **Nepal Engineering Council (NEC)** licensing examination. Currently focused on **Computer Engineering**, with planned expansion into **Civil** and **Hydropower** disciplines.

## ✨ Features

- 🎯 **Targeted Question Bank**  
  Comprehensive and curated question sets specifically for NEC Computer Engineering exams.

- 📊 **Adaptive Learning & Progress Tracking**  
  Personalized study plans and real-time progress tracking to improve learning outcomes.

- 📝 **Exam Simulation Mode**  
  Practice under realistic exam conditions to build confidence and improve performance.

- 🔒 **Secure Authentication & Data Storage**  
  Supabase-powered login and secure cloud data management for seamless user experience.

- 📱 **Cross-Platform Support**  
  Built with Flutter for a consistent experience across Android and iOS devices.

## 📦 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/muproject990/neclicensepreperation.git
   cd neclicensepreperation
````

2. **Install dependencies:**

   ```bash
   flutter pub get
   ```

3. **Set up Supabase:**

   * Create a Supabase project at [supabase.io](https://supabase.io).
   * Add your Supabase credentials in a `.env` file or directly into your config files.

4. **Run the app:**

   ```bash
   flutter run
   ```

---

## 🔐 Environment Variables

Create a `.env` file with the following (or use Flutter secure storage):

```env
SUPABASE_URL=your-supabase-url
SUPABASE_ANON_KEY=your-anon-key
```
